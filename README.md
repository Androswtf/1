# androswtf.github.io

Небольшой лендинг с калькулятором стоимости маркетинговых услуг в стиле глассморфизм.

Откройте `index.html` в браузере, отметьте интересующие услуги и количество месяцев.
Ниже представлены тарифы в виде карточек с кратким описанием входящих услуг — выберите один или несколько.
Нажмите «Рассчитать», чтобы узнать итоговую стоимость и получить бесплатную консультацию.
